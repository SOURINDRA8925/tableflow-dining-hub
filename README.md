User Requirement:

Website where users can see which food is available today.

Customers can book food in an advance of 3 hours.

For events like birthdays, the user needs to book 3-4 days in advance. They need to pay 40% beforehand. They can cancel the event until 1 day, and if they cancel, the 40% payment is not refundable.

The user can have the service of takeaway, and they have to inform us a minimum of 1 hour before.

Admin Requirement:

Salse analisis. Interactive charts

Payment chart (cash/card/UPAI)

can monitor staff attendance.

best-selling food item

For big events the admin should provide the permit for the event.

** Users' orders can be seen by the admin and the restaurant staff.

Resturent Stalf:

Can take an order using their mobile or tablet using the same website.

The entire update will be shared across the cook and the cashier.

Staff attendance will be taken from the biometrics.

Payment will be taken by the staff.
